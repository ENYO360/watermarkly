### Image Watermark Application

A simple web application for adding watermarks to images.

### How to setup on your local machine

1. Clone the repository
2. Install the required dependencies: `pip install -r requirements.txt`
3. Run the application: `python desktop_app.py`

### Web version of the application
To access the web version of the application, you can visit [Watermarkly](https://watermarkly.onrender.com/).
